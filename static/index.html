Deep Experiment: Enhanced MCGS on 5-node Type C

MCGS: 10 initial samples + 50 rollouts (vs previous 5+10). Joint LLM: 5 concurrent trials for statistical reliability.

Verdict Experiment: Conclusion-Driven Detection

Joint LLM: binary "found_defect?" (no score threshold) · MCGS: structural detection (ANY clause flagged = SCC detected) · Type C · 5n + 9n

Key Conclusions

1. Obvious Defects (Type A)
LLM maintains 100% detection up to ~60 clauses (~17K tokens). At 80+ clauses (~20K tokens), detection starts to degrade. At 200+ clauses, JSON output truncation becomes the dominant failure mode.
2. Subtle Defects (Type C)
LLM fails to detect scope expansion at all scales (0-40% detection even at 5 clauses). This type of cross-clause reasoning defect fundamentally requires multi-hop analysis — exactly what MCGS provides through sampling and search.
3. Output Token Bottleneck
At 200+ clauses, the LLM cannot produce valid JSON output within the 8192-token limit, causing 100% structural failures. MCGS avoids this by evaluating smaller subsets per call.
4. MCGS Advantage
MCGS addresses both failure modes: (a) attention degradation on large inputs via divide-and-conquer sampling, and (b) subtle cross-clause defects via multi-hop search with Online Conformal calibration.

Key Findings

1. Joint LLM: Fundamental Blind Spots
• 24n: 100% FP — always reports "defect found" even on clean legal text (avg 15.8/24 clauses flagged).
• 9n: 0% detection — misses both clean and perturbed entirely.
• 5n: 100%/100% — not discriminative.
2. MCGS: Reliable Aggregate Signal
• OC count is stable: Clean always has ~3 OC detections, Perturbed always has ~7 (+4 consistent delta).
• Specific nodes: bgb_312 and bgb_495 are consistently OC-detected only in perturbed (3/3 runs).
• Per-node Δμ is noisy due to independent LLM sampling variance.
3. MCGS vs LLM: Key Advantage
MCGS provides calibrated statistical signals (OC detection counts, aggregate risk changes) that are consistent across runs, while Joint LLM produces only binary yes/no verdicts with no calibration — either 100% FP or 0% detection.
4. Improvement Path
Paired sampling design: use the same LLM samples for both clean and perturbed evaluations, varying only the perturbation text. This would eliminate inter-run variance and improve per-node localization (the aggregate signal is already strong).
