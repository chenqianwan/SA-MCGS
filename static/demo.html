Problem: Anomaly Search on Cyclic Graphs

许多现实系统的依赖关系天然形成有环有向图——其中强连通分量 (SCC) 是异常传播和隐蔽风险的温床。

传统 MCTS 在有环图上数学上不可收敛（UCT 要求有限深度 D < ∞，环路径无上界）。

SA-MCGS 是首个使 AlphaGo 式搜索可应用于任意有环依赖图的通用框架。 通过三大核心贡献解决 MCTS 在环上的失效，并以可插拔剪枝策略适配不同领域。

Key Finding: LLM Performance Cliff

1. Attention Tipping Point
At 80 clauses (~20K tokens), LLM detection drops from 100% to 80% for obvious defects. By 120 clauses, it falls to 60%.
2. Subtle Defects Always Fail
Type C (scope expansion) detection is 0-40% at ALL scales, even with just 5 clauses. Multi-hop reasoning is fundamentally beyond single-call LLM.
3. Output Token Bottleneck
At 200+ clauses, JSON truncation causes 80-100% structural failures. MCGS avoids this via divide-and-conquer.

SA-MCGS 实验数据看板

基于 BGB (Scalability) 与 CUAD (Accuracy) 的基准测试结果，展示了 SA-MCGS 在处理复杂法律依赖图时的优越性。

1. BGB 风险子图提取效果 (节点数)

展示了在 24 节点大型 SCC 中，SA-MCGS 提取出的最小风险子图规模（平均压缩率约 60%）。

结果：在 16 个不同注入点的测试中，平均将 24 节点环压缩至 11.4 节点。

2. BGB 鲁棒性：不同注入点检测率

在 24 节点 SCC 中随机选择 16 个不同条款进行“投毒”，验证算法的稳定性。

结果：81.3% 的情况下直接锁定投毒源，100% 覆盖风险扩散路径。

3. CUAD 跨合同缺陷注入检测率 (5 类缺陷)

使用 CLAUSE Benchmark (EACL 2026) 的 5 类真实法律缺陷注入跨合同 SCC，当缺陷落入 SCC 范围时检测率极高。

结果：5 类缺陷在 SCC 范围内检测率均达 80-100%，Clean 误报率 0%。

4. CUAD 跨合同子图压缩 (3 个 Deal Package)

将同一交易下多份合同合并为统一依赖图，SA-MCGS 精准缩小跨合同 SCC 的审查范围。

结果：投毒命中率 96.3%，Top-1 排名率 70.4%，Clean 误报 0%。

5. SA-MCGS vs LLM Baselines (CLAUSE Benchmark)

对比 EACL 2026 CLAUSE 论文的 4 个 LLM 基线，SA-MCGS 在 SCC 范围内的 3 类缺陷检测率均远超纯文本推理方法。

结果：SA-MCGS 在结构性缺陷检测上达 100%，而最强 LLM (Gemini-2.0) 仅 55.8%。

6. BGB 不同 SCC 规模验证 (5n / 9n / 24n)

在 BGB 16,000 节点大图中，对 3 种不同规模的 SCC 均进行了注入检测实验，验证算法的可扩展性。

结果：5 节点环 LLM 可处理，9 节点环开始出现精度损失，24 节点环 LLM 仅能定位 1/5 但 SA-MCGS 仍成功定位。

7. Ablation: TreeMCTS vs SA-MCGS (Q-Spread)

在真实合同 (CUAD Deal Package) 上，标准树搜索 Q 值被环稀释为 ~0，而 SA-MCGS 保持高区分度。

结果：SA-MCGS Q-Spread 达 0.800，TreeMCTS 仅 0.058-0.097 (8-14x 差距)。

8. BGB 24n 逐注入点子图大小

在 24 节点 SCC 的 16 个不同注入点上，展示每次提取的子图节点数与命中情况。

结果：子图规模 7-22 节点，命中率 81.3% (13/16)，最佳压缩 71% (24→7)。
