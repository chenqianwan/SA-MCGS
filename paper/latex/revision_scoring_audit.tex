\section{Scoring, Uncertainty, and Configuration Audit}
\label{app:scoring_audit}

All five models use a unified strict terminal-output policy. A strict-invalid output receives zero for Root@3, Risk-any, and Risk-all; each binary denominator remains 80. Compression is averaged only over defined valid outputs, with denominators reported separately. The archived local parsing fallback is retained within otherwise valid system outputs. Qwen3.5-9B metricwise reparsing is reported separately as a scoring sensitivity, without new model calls.

The 80 variants comprise four variants from each of 20 physical source SCCs. Paired intervals use 20,000 percentile-bootstrap draws (seed 8229), resampling source SCCs jointly across methods, variants, and the five fixed models. For pooled differences, we first average the 20 model--variant differences within each source, then average sources. Model-specific differences average four variants per source. The comparison uses one frozen terminal outcome per model--method--variant from historical execution batches. Its intervals reflect variation across the selected sources; they do not measure repeated-run seed variation, unseen-model variation, or natural-risk prevalence. Intervals are descriptive and unadjusted for multiple comparisons.

\paragraph{Historical configuration provenance.}
These terminal outcomes come from archived batches. The supplementary model--method configuration ledger distinguishes recorded settings from current code defaults. In particular, Qwen2.5-72B LEA records an AWQ checkpoint; the earlier One-shot and \samcgs{} outputs do not establish an identical provider snapshot or quantization. The comparison is therefore within a reported model family, with incomplete backend matching. Early GPT-4o, Gemini, and Qwen2.5 settings cannot all be retrospectively verified from raw artifacts. Llama and Qwen3.5 batch protocols record temperatures 0 for One-shot and 0.4 for local evaluation, token caps 12,000 and 2,048 respectively, and Python seed 42; API sampling seeds are not recorded. These provenance limits preclude treating all historical outcomes as a fully contemporaneous, configuration-controlled experiment.
