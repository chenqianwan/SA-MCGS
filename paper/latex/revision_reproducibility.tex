\section{Reproducibility Materials}
\label{app:reproducibility}
The supplementary archive contains anonymized case-level scoring inputs, stable source identities, fixed analysis protocols, paired-bootstrap scripts, the same-trace selector inputs and separately stored evaluation labels, mock diagnostic records, relevant source snapshots, and an input-hash manifest. A single offline verification command regenerates the reported summaries without credentials, model calls, or network access. Historical raw model responses and complete provider snapshots are not all redistributable or reconstructible from these minimal inputs; the archive states what each check does and does not reproduce.
