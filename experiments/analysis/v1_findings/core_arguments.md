# SA-MCGS 实验核心发现与学术论证 (v1)
日期: 2026-04-20
数据源: BGB (德国民法典) Focus Subgraph (57 nodes, 174 edges)
LLM: DeepSeek-Chat (Cloud API)

## 1. 核心论点：结构化上下文的去偏作用 (De-biasing)
**现象描述**: 
- **Direct LLM (纯 LLM)**: 在评估原始 BGB 条文（Baseline）时，往往会给出极高的风险分（如 0.9），表现出“惊弓之鸟”式的过度敏感。
- **SA-MCGS (完整系统)**: 在同样的 Baseline 下，风险评分被修正回了理性的低位（约 0.15）。

**学术结论**: 
通用 LLM 在缺乏法律逻辑链条时，无法区分“严密的法律义务”与“恶意的法律风险”。SA-MCGS 通过构建 Dependency Graph，为 LLM 提供了上位法约束和前置条件的逻辑上下文，成功将基准风险还原至真实水平。这证明了**结构感知（Structure-Awareness）是实现准确法律风险评估的必要前提**，而非可选优化。

## 2. 实验发现：风险增量识别的灵敏度 (Sensitivity)
**对比分析**:
- 在注入 `type_a`（内容篡改）缺陷后，SA-MCGS 的风险增量 ($\Delta$ MCGS) 达到了 **+0.700** 以上。
- 纯 LLM 由于基准值（Baseline）已经处于 0.9 的饱和状态，其增量 ($\Delta$ LLM) 几乎为 **0.000**，导致其完全失去了对风险注入的检测能力。

**学术价值**: 
这组对比有力地反驳了“直接使用 GPT-4 就能做法律审计”的观点。如果没有 SA-MCGS 建立稳定的逻辑基准，LLM 会因为“基准漂移”而产生大量误报，并对真实的风险注入产生“脱敏”。

## 3. 模块消融实验结论 (Ablation Study)
- **DAG Evaluator**: 在单向依赖链条中表现极其稳健，能够精准传导风险。
- **SCC Sampler + MCGS**: 在循环依赖（R3_SCC）中，通过随机多次采样捕捉到了逻辑闭环中的不确定性，这是纯 LLM 无法处理的逻辑黑洞。
- **Graph Pruning**: 保证了在处理 BGB 这种大规模真实法律文本时的推理效率，排除了冗余引用带来的噪音干扰。

## 4. 法律健全性假设的验证
实验数据支持了“成熟法律体系是健全的”这一基本假设。
- 当注入的风险在逻辑上被上位法屏蔽时，SA-MCGS 能够给出低分（如 0.25），识别出“无效风险”。
- 这证明了 SA-MCGS 具有**法律逻辑的自愈识别能力**，能够过滤掉那些字面上看起来危险但在法律框架下无法生效的伪风险。
