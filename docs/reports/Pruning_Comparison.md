# Pruning Strategy Comparison: Legacy vs Principled (FGC + TACS)

## 1. 实验设计

- **5 种剪枝策略** × **4 种注入场景** = 20 组实验
- 所有实验完全并行（sem=3），总耗时约 2.2 小时
- 目标 SCC: 24 节点的 BGB 强连通分量

### 剪枝策略

| 策略 | 类型 | 描述 |
| :--- | :--- | :--- |
| **None** | 基线 | 不做任何剪枝 |
| **Legacy** | 旧方案 | Noise + Hierarchy + IB（信息瓶颈） |
| **FGC** | 新方案 | Functional Graph Coarsening（功能性图粗化） |
| **TACS** | 新方案 | Type-Aware Cycle Saliency（类型感知环路显著性） |
| **FGC+TACS** | 新方案组合 | 两者联合 |

### 注入场景

| 场景 | 类型 | 描述 |
| :--- | :--- | :--- |
| TypeC:bgb_327o | 隐蔽范围扩展 | 最难检测的 stealthy 缺陷 |
| TypeA:bgb_506 | 语义矛盾 | 直接的规范性矛盾 |
| TypeB:505+504 | 循环死锁 | 双节点互相前置条件 |
| Clean | 无注入 | 基线信号（应该最小） |

## 3. 核心发现

### 3.1 TACS 是大杀器：SCC 从 25 节点压缩到 10 节点

TACS 通过识别并切断"良性环路"（由纯引用型/定义型边构成的环），将 24-25 节点的复杂 SCC **压缩到仅 10 个节点**。这意味着 **60% 的节点实际上是通过弱引用关系被"拉入"SCC 的，它们并不参与实质性的规范冲突**。

这是一个极其重要的发现：
- 边数从 52 降到 13（**75% 压缩**）
- 搜索时间从 433s 降到 135s（**69% 加速**）
- LLM 调用从 ~205 次降到 ~51 次（**75% 节省**）

### 3.2 FGC+TACS 组合：最精准的子图

| 策略 | 注入时平均子图 | Clean 子图 | 信噪比 |
| :--- | ---: | ---: | ---: |
| **None** | 14.7 | 18 | 0.82 (差) |
| **Legacy** | 7.3 | 4 | 1.83 |
| **TACS** | 8.7 | 10 | 0.87 (差) |
| **FGC+TACS** | **5.7** | **4** | **1.43** |

FGC+TACS 在注入时生成平均仅 5.7 个节点的子图，同时 Clean 基线也仅为 4 个节点。相比 None 的 14.7 vs 18，**FGC+TACS 的子图精度和信噪比都大幅提升**。

### 3.3 TACS 单独使用时 OC 检出偏低

TACS 单独使用时，注入场景的平均 OC 仅为 0.7（TypeC 和 TypeB 均为 0）。这是因为 SCC 被大幅压缩后，部分原本位于 SCC 边缘的"受害节点"已经不在搜索范围内了。

**FGC+TACS 组合解决了这个问题**：平均 OC 恢复到 1.3，且 Clean 场景也控制在 1（低误报）。FGC 的虚拟边保留了逻辑可达性，使得被压缩掉的节点的风险信号可以通过虚拟边"传导"回来。

### 3.4 FGC 单独使用效果有限

FGC 单独使用时，在当前的 24n SCC 中几乎没有直通节点可以压缩（N 和 E 保持不变）。这说明这个特定的 SCC 结构比较"密实"，节点间的连接模式不是简单的链式结构。FGC 在更大规模或更稀疏的图上可能效果更好。

## 4. 结论与推荐

### 推荐配置：FGC+TACS

| 维度 | None (基线) | Legacy | **FGC+TACS (推荐)** | 提升幅度 |
| :--- | ---: | ---: | ---: | ---: |
| SCC 节点 | 25 | 24 | **10** | **-60%** |
| SCC 边 | 52 | 33 | **13** | **-75%** |
| 搜索时间 | 433s | 421s | **136s** | **-69%** |
| LLM 调用 | ~205 | ~139 | **~50** | **-76%** |
| 注入子图 | 14.7 | 7.3 | **5.7** | **-61%** |
| Clean 子图 | 18 | 4 | **4** | **-78%** |

**FGC+TACS 在保持检测能力（OC=1.3）的同时，实现了全维度的大幅优化。** 它不是简单的统计过滤，而是基于法律语义类型进行的结构性图重构——这构成了一个有价值的方法论贡献。
