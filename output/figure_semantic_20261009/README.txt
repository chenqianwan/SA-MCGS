Design
Remove the previous decorative title icons, colored title strips and broad tinted module backgrounds. Use open graph windows, processor outlines, symbolic observations and shared record structures inside the evidence flow. Color is restricted to meaningful selected records, method anchors, stored observations and feedback paths. The method palette remains gray Full-SCC, orange LEA, neutral TreeMCTS and blue SA-MCGS.

Scientific meaning
All graph topology and prior mechanism equations are retained. Full-SCC is the existing one-shot baseline. LEA uses fixed overlapping node-anchored windows. TreeMCTS stores path-specific states, whereas SA-MCGS stores evidence under shared graph-object keys and selects a terminal core only after T. Mean-risk ranking is separate from core priority.

The new record shapes are symbolic, without empirical values or measured counts. A row of observation tokens with an ellipsis denotes a node's risk-score history; it does not say the node was observed in every rollout. Normalized support e_t(v) and program-computed OC remain parallel memory quantities; no arrow asserts that mean risk alone determines OC. Only the front pair-record sheet contains A-D, denoting one shared unordered-pair entry, not duplicate pair states. A-D is not an original directed edge.

Symbols
S=(V_S,E_S): cyclic component. W_t: bounded local window. M_t: accumulated evidence memory. H_T: terminal returned subgraph. B(S): core-size cap. e_t(v): normalized evidence. qbar_t(v): mean observed risk. m_t(p): unordered-pair support. O_t: accumulated OC-flagged set. Select/Eval/Update/Core/rank are schematic operation names.
