# 同预算重复采样基线方案

状态：已完成 4 例 GPT-4o 试跑，费用估值 $6.00，低于 $15 上限；正式对比尚未运行。见 [试跑报告](experiments/equal_budget_pilot_20261008/REPORT_ZH.md)。只增加重复采样和一次评选，保留原方法的主要逻辑；结果如实报告。

| 方法 | 做法 |
|---|---|
| LEA Best-of-N | 独立运行多次原版 LEA；每次仍用四节点窗口和原聚合规则，得到一个完整候选。各次采样不复用上一轮答案缓存。 |
| Full-SCC Best-of-N | 用原全图提示独立生成多个候选；每次都读取完整 SCC，保留原输出格式。 |

统一评选：同一模型再评一次，读取原文和匿名、随机排序的候选，只选一个已有完整答案。判断证据是否受原文支持、冲突双方是否完整、是否带入多余节点；不重新生成或合并答案。评选不读取标准答案、真实 Risk-all 或 SA-MCGS 结果。规则在正式评测前固定。

预算：先按约 80% 生成候选、20% 留给评选估算；逐例先预留评选所需输入和输出额度。沿用已有用量粗估，LEA 可重复约 2–3 次，Full-SCC 约 6–8 次，实际次数由文本长度和剩余 token 决定。已有每例 181K / 226K token 是成本估算均值，正式上限须预先冻结。

同一案例、同一模型下三种方法使用相同 token 上限；所有生成、评选及可见重试用量计入。预算不足以完成下一轮时停止，不用无意义调用凑数；同时报告实际消耗，不能把相同上限写成实际消耗完全相同。

固定采样配置，保留各方法原生输出节点集合，报告实际节点数、压缩率及任务指标；共同节点上限仅作离线诊断。无效候选保留记录；全无效则该案例记失败。评选失败时只在剩余预算内重试，仍失败则记失败；不人工挑答案。

试跑发现：共同 160K token 上限下，实际用量仍有差距。保守评选预留使 CUAD LEA 只生成 1 个候选，不能视为重复采样增益证据。正式实验前需按实际候选规模调整评选预留，再冻结预算规则。

本轮不增加新检索、多尺度窗口、关系记忆或自适应搜索，也不同时改写无冲突判定接口。旧版用标准答案选择 Top-3-from-10 的方式不用于本实验。
