# 本轮图表口径

- 问题：重复采样后，风险端点、完整预设证据节点和根因排名是否一起改善，代价是多少？
- 结论边界：4 个不同领域的注入案例、单模型。端点覆盖与预设证据节点完整性给出不同排序；重复后主要命中率未改善，部分证据覆盖下降。只描述这次试跑。
- 图 1：上部为核心定位/覆盖指标；下部展示全部案例的根因名次和证据节点保留数，定位汇总差异来源。Evidence-all 是本次新增离线诊断。
- 图 2：输入/输出 token、费用、请求时间跨度、压缩率，解释重复代价及不同输出规模。保留所有 4 个案例的时间和压缩率散点。
- 类型：quantitative grid；Python / matplotlib；内部中文结果汇报，220 mm 宽，最小文字 8 pt。导出 PNG、可编辑 SVG/PDF，保留图源、脚本与校验记录。
- 样本单位：每域一个来源 SCC、一个注入变体。首次候选是对应完整流程的子集，不是额外实验；所有 20 条结果均展示，无排除。
- 汇总：二元命中率分母固定为 4；节点召回、压缩率和倒数排名取每例宏平均。时间统一用对应 API 请求第一次 reserve 至最后一次 finish 的跨度。
- 不做显著性检验或种子稳定性推断；案例是选择的开发样本，不给推断性误差条。逐例数值/散点完整展示。
- Evidence-all 只检查注入方案预设的 evidence_nodes（包括 bridge）是否全部保留，不验证关系、方向或论证。其余节点未全量标负，不计算真实 precision/F1/FPR。
- 效果与消耗使用实际记录；共同 160K 上限不等于实际 tokens 相等，CUAD LEA 只有一次候选。费用为 usage 估值；首次行不得与最终行重复相加。
