## 现在冻结的筛选规则

满足任一项即选入；每个 case 按同一规则筛选，不使用算法成绩：

1. 前两位的冲突存在性判断不同。
2. 至少一位认为判断材料不充分。
3. 至少一位信心不高于 2/5。
4. 至少一位给出“存在且充分”时，最小证据集或修复材料集的 Jaccard 重合度 **严格小于 0.5**。

重合度为交集段落数 / 并集段落数；双方均空记为 1。恰好 0.5 不纳入。双方均判负例时，不因修复材料差异单独入选，因为该集合不用于正例定位指标。

规则是在收到前两份标注后制定的定向复核规则，不称事前预注册。内部清单保留全部 42 项的入选/未入选决定，未入选不代表两位的所有段落选择完全相同。展示顺序沿用原 expert_3 随机序列的子序列。
